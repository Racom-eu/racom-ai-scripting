# rr_netconf_mgmt method catalog

Generated by `scripts/gen_catalog.py` from the `rac_netconf_mgmt` submodule — do not edit by hand.
The library is small: `NetconfDevice` owns the SSH/NETCONF session (ncclient) and
`NetconfConfig` holds one configuration (XML + the YANG schemas needed to read it, via libyang).
**[DESTRUCTIVE]** = writes to the device; needs explicit user confirmation.

CLI: `netconf get|leaf|set|edit|state|rpc …` wrap these (see SKILL.md).


## NetconfDevice

NETCONF device interface combining connection lifecycle with config and schema operations. Implements SchemaFetcherProtocol for use with NetconfConfig.from_device(). Not thread-safe — do not share a single instance across threads.

- `__init__(host: str, port: int = 830, user: str = '', password: str = '', timeout: int = 30, hostkey_verify: bool = True, hostkey_b64: str | None = None, use_libssh: bool = True, **connect_kwargs: Any) -> None`  
  Initialize device interface with connection parameters.
- `connect() -> None`  
  Establish NETCONF connection to the device.
- `reconnect() -> None`  
  Close any existing connection and establish a new one.
- `close() -> None`  
  Close the NETCONF connection.
- `__enter__() -> 'NetconfDevice'`  
  Context manager entry — connect to device.
- `get_config(xpath: str | None = None, datastore: str = 'running') -> NetconfConfig`  
  Retrieve configuration from the device.
- `set_config(config: NetconfConfig, operation: str = 'merge', datastore: str = 'running') -> None` **[DESTRUCTIVE]**  
  Write configuration back to the device.
- `get_schema(identifier: str, revision: str | None = None) -> str`  
  Fetch raw YANG schema string from the device.
- `fetch_config_xml(xpath: str | None, xmlns: dict[str, str], datastore: str = 'running') -> tuple[str, set[str]]`  
  Fetch raw XML configuration string from the device.
- `get_module_list() -> list[tuple[str, str | None, str | None]]`  
  Return all YANG schemas from NETCONF Monitoring with name, revision, and namespace.

## NetconfConfig

Source-agnostic NETCONF configuration object. Holds raw XML configuration and all YANG schemas needed to parse it. Converts to Python dict on demand via libyang.

- `__init__(xml: str, dep_yang: dict[str, str] | None = None) -> None`

- `from_device(device: SchemaFetcherProtocol, xpath: str | None = None, datastore: str = 'running') -> 'NetconfConfig'` *(classmethod)*
