# rr_netconf_mgmt method catalog

Generated by `scripts/gen_catalog.py` from the `rac_netconf_mgmt` submodule — do not edit by hand.
The library is small: `NetconfDevice` owns the SSH/NETCONF session (ncclient) and
`NetconfConfig` holds one configuration (XML + the YANG schemas needed to read it, via libyang).
**[LOCAL ONLY]** does not contact the RACOM device; local objects/files may change.
**[DEVICE READ]** may contact/read the device without device-side writes or state-changing actions.
**[WRITE AUTH REQUIRED]** requires explicit approval and `RACOM_ALLOW_WRITE=1`.
Authorization includes active operations and need not involve persistent configuration.
Unknown or ambiguous methods require write authorization.
Labels describe device-side safety, not whether a local Python object is mutated.
`NetconfConfig.set` and `update_from_dict` mutate local XML only: [LOCAL ONLY].
`NetconfDevice.set_config` separately sends changes to the device: [WRITE AUTH REQUIRED].
Library-member classifications and raw NETCONF RPC classifications use separate contexts.

CLI: `netconf get|leaf|set|edit|state|rpc …` wrap these (see SKILL.md).


## NetconfDevice

  Initialize device interface with connection parameters.

  Establish NETCONF connection to the device.
- `reconnect() -> None` **[DEVICE READ]**\
  Close any existing connection and establish a new one.
- `close() -> None` **[DEVICE READ]**\
  Close the NETCONF connection.

## NetconfConfig

## SchemaFetcherProtocol

Interface for objects that can supply YANG schemas and raw config XML. NetconfDevice satisfies this protocol.


These are interface declarations without executable implementations.
Their behavior cannot be established for arbitrary implementers, so their classification
defaults to [WRITE AUTH REQUIRED]. The audited `NetconfDevice.get_schema`
implementation is separately classified [DEVICE READ].

- `get_schema(identifier: str, revision: str | None = None) -> str` **[WRITE AUTH REQUIRED]**

- `get_module_list() -> list[tuple[str, str | None, str | None]]` **[WRITE AUTH REQUIRED]**
